# Spotlight website

Static site (HTML, CSS, JS). No build step.

## Files
index.html, style.css, main.js, robots.txt, sitemap.xml, llms.txt,
logo-full.png, logo-mark.png, logo-wordmark.png, favicon-32/180/512.png,
spotlight.mp4 (hero video), poster.jpg (video placeholder), README.md

## Run locally
Open index.html in a browser, or use the VS Code Live Server extension.

## Before you go live
1. Replace `YOUR-DOMAIN.com` in index.html, robots.txt, sitemap.xml and llms.txt.
2. Set `CONTACT_EMAIL` in main.js to your real address.
3. Edit the wording in index.html to match your real services.

## Deploy
1. Push this folder to a GitHub repo.
2. On vercel.com choose Import Project, pick the repo, click Deploy.
3. Every push to `main` updates the live site.
